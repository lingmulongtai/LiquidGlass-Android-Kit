Start building

Use the whole template or install only the library.

Start a new app

Create a repository from the template and open it in Android Studio with Android SDK 36 and JDK 17. Run the included gallery before adding your own screens.

Use the template ↗

Add to an existing app

Download the Maven ZIP, unpack it into third_party/liquidglass, and add the local Maven repository to Gradle. Then include the library.

build.gradle.kts
implementation("io.github.lingmulongtai:liquidglass-compose:0.1.0")
